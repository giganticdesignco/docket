# Docket

Gigantic Design Co.'s time, task, retainer, expense, quote and invoice
app. Nuxt 4 and Supabase, deployed to Vercel on a push to `main`.

- `npm install` then `npm run dev`; copy `.env.example` to `.env` and
  fill it in.
- `npx nuxt typecheck` before a commit.
- `CLAUDE.md` has the rules, `docs/handoff.md` the current state,
  `docs/guide.md` the user guide (also at `/help` in the app), and
  `schema.sql` the database.
